# Password-Strength-Checker
A Python program that evaluates password strength based on common security criteria.

## Features

- Check password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numeric digits
- Classifies password strength based on the above factors

## Concepts Used
- Strings
- Conditional Statements (if, elif, else)
- Loops
- Functions
- String Methods

## Example

  ### Input
  Password: Password123

  ### Output
  Strong Password

## Purpose
This project was created to practice Python programming fundamentals while implementing a simple real-world security application.
